# Архив между эпохами

«Письмо без адреса» — одиночное расследование в браузере. Переключайся между архивом 1986 года и музеем 2086 года, собирай документы и выясни, откуда в музейной сводке взялся адрес, которого нет на конверте.

## Как запустить

Распакуй проект и открой `index.html` в браузере. Все материалы входят в проект. Играть можно с клавиатуры и с сенсорного экрана. Для переключения эпох нажимай `1` и `2`. Прогресс хранится в браузере. Если браузер блокирует хранилище для локальных файлов, игра продолжит работать до закрытия вкладки.

## Публикация

Все файлы из папки проекта можно разместить в корне одного репозитория GitHub. В **Settings → Pages** выбери **Deploy from a branch**, затем ветку `main` и папку `/ (root)`. Сборка, API и сервер приложения для игры не требуются.

## Как использован ИИ

Codex помог разработать механику, написать сценарий и реализовать игру. Обе иллюстрации архива созданы с помощью ImageGen. Классификатор внутри игры действительно сравнивает размеченные примеры по общим словам. Музейный терминал показывает подготовленный сюжетный черновик и не обращается к внешней модели. События и персонажи вымышлены.
