# ИИ под микроскопом

[Открыть приложение](https://eklimiks.github.io/archive-between-eras/)

«ИИ под микроскопом» — браузерная лаборатория, где можно научиться проверять ответы искусственного интеллекта и применять тот же способ к своим текстам.

- **Тренажёр.** Четыре учебных дела про даты, цитаты, статистику и работу с оригиналами. Выберите утверждение, приложите фрагменты документов, вынесите вердикт и перепишите ответ. Разбор объяснит каждый вердикт и покажет пример ответа по источникам. Новые дела можно проходить без подсказок.
- **Моя проверка.** Вставьте свой ответ ИИ, выделите из него утверждения, приложите найденные материалы и запишите собственный вывод. Вы оцениваете утверждения сами.
- **История.** Открывайте предыдущие разборы и скачивайте учебные и собственные отчёты в TXT.
- **Сюжетное дополнение.** [«Архив между эпохами»](https://eklimiks.github.io/archive-between-eras/archive.html) — одиночная игра «Письмо без адреса». В двух эпохах игрок ищет оригинал записки и восстанавливает историю, которую музейный ИИ составил по обрывку.

## Запуск

Откройте ссылку выше. Для работы без интернета распакуйте ZIP и откройте `index.html` в браузере. Нужен JavaScript. Сборка, аккаунт, ключи и сервер приложения не требуются. Исходные тексты, черновики и история сохраняются в браузере. Если браузер блокирует локальное хранилище, приложение работает до закрытия вкладки, а отчёты по-прежнему можно скачать.

## Как использован ИИ

Codex помог разработать концепцию, интерфейс, учебные сценарии и код. Обложка и шесть сцен сюжетной игры созданы с помощью ImageGen. Учебные материалы вымышлены, а разборы основаны на заранее составленных документах и критериях. При работе приложение не обращается к внешней модели. Оно помогает организовать проверку, сохраняя решение за человеком.

В игре по клавишам `1` и `2` можно переключать эпохи. Предметы можно перетаскивать или выбирать поочерёдно. Кнопка «Игра на весь экран» разворачивает саму игровую панель.
