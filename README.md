# Архив между эпохами

«Письмо без адреса» — одиночное расследование в браузере. Накануне выставки «Город говорит» музейный ИИ составляет биографию Лиды Ветровой по обрывку её записки. Игрок исследует лабораторию, мастерскую и хранилище в 1986 и 2086 годах, восстанавливает письмо по частям и проверяет музейную сводку по оригиналу. В финале игрок выбирает, как представить историю посетителям.

[Играть на GitHub Pages](https://eklimiks.github.io/archive-between-eras/)

## Как запустить

Распакуй проект и открой `index.html` в браузере. В меню доступна предыстория, а после входа кнопка «Игра на весь экран» разворачивает игровую панель. Нажимай на предметы в сцене, чтобы осмотреть их и пополнить инвентарь. Перетаскивай предметы на механизмы мышью или пальцем. Можно также выбрать предмет, а затем активировать механизм щелчком, касанием или клавишей Enter. Клавиши `1` и `2` переключают эпохи.

Кнопка «Сравнить эпохи» совмещает два снимка комнаты. Двигай границу прямо на сцене или ползунком, чтобы осмотреть оба кадра и записать наблюдение в журнал.

Прогресс хранится в браузере и открывается через кнопку «Продолжить». Если браузер блокирует хранилище для локальных файлов, игра продолжит работать до закрытия вкладки.

## Публикация

Все файлы из папки проекта можно разместить в корне одного репозитория GitHub. В **Settings → Pages** выбери **Deploy from a branch**, затем ветку `main` и папку `/ (root)`. Сборка, API и сервер приложения для игры не требуются.

## Как использован ИИ

Codex помог разработать механику, написать сценарий и реализовать игру. Шесть сцен и обложка созданы с помощью ImageGen. Классификатор сравнивает размеченные примеры по общим словам. Музейный терминал использует подготовленный сюжетный черновик и не обращается к внешней модели. События и персонажи вымышлены.

Шрифты Unbounded и Exo 2 включены в проект по лицензии SIL Open Font License. Тексты лицензий находятся в `assets/fonts/`.
