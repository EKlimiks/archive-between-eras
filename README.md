# Архив между эпохами

«Письмо без адреса» — одиночное расследование в браузере. Исследуй лабораторию, мастерскую и хранилище в 1986 и 2086 годах. Собери улики, восстанови оригинал письма и выясни, откуда в музейной сводке взялся адрес, которого нет на конверте.

[Играть на GitHub Pages](https://eklimiks.github.io/archive-between-eras/)

## Как запустить

Распакуй проект и открой `index.html` в браузере. Нажимай на предметы в сцене, чтобы осмотреть их и пополнить инвентарь. Перетаскивай предметы на механизмы мышью или пальцем. Можно также выбрать предмет, а затем активировать механизм щелчком, касанием или клавишей Enter. Клавиши `1` и `2` переключают эпохи. Прогресс хранится в браузере. Если браузер блокирует хранилище для локальных файлов, игра продолжит работать до закрытия вкладки.

В расширенной версии расследование начинается с первой новой загадки. У неё отдельное сохранение.

## Публикация

Все файлы из папки проекта можно разместить в корне одного репозитория GitHub. В **Settings → Pages** выбери **Deploy from a branch**, затем ветку `main` и папку `/ (root)`. Сборка, API и сервер приложения для игры не требуются.

## Как использован ИИ

Codex помог разработать механику, написать сценарий и реализовать игру. Шесть сцен созданы с помощью ImageGen. Классификатор сравнивает размеченные примеры по общим словам. Музейный терминал использует подготовленный сюжетный черновик и не обращается к внешней модели. События и персонажи вымышлены.

Шрифты Unbounded и Exo 2 включены в проект по лицензии SIL Open Font License. Тексты лицензий находятся в `assets/fonts/`.
